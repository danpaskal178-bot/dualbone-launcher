# DualBone

Кастомный лаунчер для Minecraft, написанный на C# (.NET, WPF, MVVM).

## Возможности
- Установка и запуск разных версий Minecraft
- Вход через Microsoft-аккаунт
- Поддержка модлоадеров (Forge, Fabric и др.)
- Управление модами, ресурспаками, шейдерами, мирами
