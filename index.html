DualBone для Minecraft

Настоящий вход через Microsoft, любые версии и загрузчики, моды с Modrinth, свои сервера. Никаких обходов покупки игры — только то, что действительно работает.

Windows 10/11·нужен купленный Minecraft: Java Edition

Девять слотов, девять функций

Всё, что уже реально работает в лаунчере — без заглушек.

01

Настоящий вход

OAuth-вход через Microsoft, проверка владения игрой, реальный профиль и скин — без обходов и без пароля внутри лаунчера.

02

Версии и загрузчики

Vanilla, Fabric, Forge, NeoForge, Quilt — список версий тянется прямо из официального манифеста Mojang.

03

Моды с Modrinth

Поиск и установка модов под нужную версию и загрузчик — прямо внутри установки, без лишних вкладок браузера.

04

Ресурспаки

Список, включение и выключение синхронизировано с настройками самой игры — не отдельная выдуманная галочка.

05

Шейдеры

Установка и удаление шейдерпаков в одном месте, рядом с остальным содержимым установки.

06

Серверы

Настоящий пинг по протоколу Minecraft — онлайн игроков, версия, задержка в мс, MOTD.

07

Логи

Отдельно лог самого лаунчера и лог игры, с фильтром «только ошибки и предупреждения».

08

Гибкие настройки

RAM по умолчанию, число потоков загрузки, папка кэша — то, что реально меняет поведение установки.

09

Светлая и тёмная тема

Полноценная смена палитры на лету, с плавным переходом между темами — как у этой самой страницы.
